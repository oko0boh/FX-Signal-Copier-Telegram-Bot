## Summary
The book has no single pair table. It has four different tables for four
different questions: which timeframe a style trades, which timeframe supplies
the key level, which timeframe is used to profile and enter, and a simple
daily-4H-15m plan. None of them is the rulebook's "M→D, W→4H, D→1H, 4H→15m".

## Definitions
- **Style by timeframe** [S, clear], p.89: monthly = position trading; weekly
  = swing; daily = short-term; 4H = intraday. Trade the range of that candle.
  Scalper trades the hourly range.
- **Alignment layers** [S, clear], p.90: CRT and key levels on a higher
  timeframe; structure on an intermediate timeframe (optional); profiling and
  entry on a lower timeframe.

## Tables (all [S], clear)
**By style, p.91**
| Style | Key level + CRT | Structure | Profiling + entries |
|---|---|---|---|
| Swing | Monthly | Daily | H4 |
| Short term | Weekly | H4 | H1 |
| Intraday | Daily / H4 | H1 | M15 |
| Scalping | M15 | M5 | M1 |

**Key level vs profiling, p.87:** Daily KL / H1; H4 KL / M15; H1 KL / M5;
M15 KL / M1.

**CRT to key-level timeframe, p.205:** 15m→1h(+4h); 1h→4h(+D); 4h→D(+W);
D→W(+M); W→M(+Y). This matches the rulebook's "key level → expansion" table
(option c in C-01).

**Simple plan, p.264 and p.253:** daily (draw on liquidity, key level, CRT) →
4H (narrative, key level and CRT at key times) → 15M (profile, order block
entry). p.253 words the intraday set as daily/4H = draw, key level and CRT;
1H = order flow and profiling; 15M = entries.

**Student-notes version, p.73 [S]:** daily finds the turtle soup, 4H finds the
CRT, 15M gives the entry. p.14 [R handwritten]: the 1H and 4H give your entry
and your DOL; use the 9 o'clock 4H candle model. [clear]

## Rules / conditions
